Your win: identify the values crossing each boundary, so you know where to make a data-related change. About seven minutes.

First recall: which operation changes parameters? Then trace the following files in order.

BoundaryWhat travels through it
maskrcnn_benchmark/data/datasets/coco.py
__getitem__		Loads an image and annotations; builds a BoxList holding boxes, labels, and parsing annotations; transforms image and target together; returns image, target, index.
maskrcnn_benchmark/data/transforms/build.pyResize, possible horizontal flip, conversion to tensor, normalization. Spatial changes must keep the labels aligned with the image.
maskrcnn_benchmark/data/collate_batch.pyCombines samples into an ImageList plus separate per-image targets and IDs. ImageList pads images to a common size.
maskrcnn_benchmark/modeling/detector/generalized_rcnn.pyBackbone consumes [B, 3, H, W] image tensors. B is the batch size; H and W are padded dimensions. Features are learned spatial representations.
maskrcnn_benchmark/modeling/roi_heads/parsing_head/parsing_head.pyTraining resamples regions against targets, extracts region features, predicts parsing and edges, and computes losses.
maskrcnn_benchmark/modeling/roi_heads/parsing_head/outputs.pyFor the selected config, parsing logits have 20 class channels and configured spatial resolution 256 × 256 per region. Logits are raw scores, not class IDs. Edge output has two channels.

The number of regions is not the number of images: one image may contain several people. A region's 256 × 256 prediction is also not the full original image size. Postprocessing maps predictions back to image space.

Practice: predict the contract

If two images yield five selected regions altogether, what shape should the parsing logits have in this configuration?

Feedback

[5, 20, 256, 256]: regions, classes, height, width. The leading dimension here counts regions.
