# Mission: Develop AIParsing independently

## Why
Learn the existing AIParsing code and PyTorch workflow well enough to continue coding this project independently.

## Success looks like
- Trace an image and its labels through training and evaluation.
- Explain model construction, forward computation, loss, gradients, and updates.
- Locate and implement a small change, predicting affected shapes and checking its behavior.

## Constraints
- Research familiarity, but no hands-on model creation or PyTorch experience.
- Teach through this repository in short steps with exercises.

## Out of scope
- None explicitly specified.
